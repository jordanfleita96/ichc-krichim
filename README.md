# International Christian Church – Krichim

Official website source for **International Christian Church – Krichim** / **Интернационална Християнска Църква – Кричим**.

- English is the default language.
- Bulgarian is available through the EN/BG switch.
- Regular services: Friday 18:00 and Sunday 10:00.
- Senior Pastor: Angel Yordanov / Главен Пастор Ангел Йорданов.

This is the initial simple version of the website and can be expanded as the new church building is completed.
